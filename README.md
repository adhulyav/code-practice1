# code 3:Number Guessing Game
-A simple Python game where the computer randomly selects a number between **1 and 100**, and the player tries to guess it.
### Features
- Generates a random number.
- Gives hints when the guess is high or low.
-Continues until the correct number is guessed.
### Setup
- Download or clone this repository.
 -Open the project folder in a terminal.
  # how to play 
-Enter a number between **1 and 100** and follow the hints until you guess correctly.
# Language: Python
